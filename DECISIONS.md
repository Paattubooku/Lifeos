Plans (routine blocks, dishes, program) are also edited offline through the sync queue (F02), so they need idempotent upserts and soft delete too. `client_id` defaults to a random uuid so server-side inserts (seed, Edge Functions) don't need one.

- 2026-11-26 · **Root cause of the iPhone keyboard closing in every text box.** `TextField` added `shadowColor` to its frame only while focused (the focus glow). The `UITextField` was re-parented and resigned first responder about 50 ms after focus. On-device proof: the Keyboard test screen showed a bare `TextInput` keeping focus while the app's `TextField` blurred 50 ms after every focus. Fix: the frame always carries the same shadow props and only `shadowOpacity` changes. Rule for the codebase: never add or remove `shadowColor` (or other stacking-context props such as opacity ≠ 1, transform, zIndex) on an ancestor of a focused `TextInput` in response to focus.
