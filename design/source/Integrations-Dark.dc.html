Setup guides
iPhone Shortcuts · SMS automation
1Shortcuts → Automation → New → Message. Message contains: debited. Run immediately.
2Add action Get Contents of URL: POST https://api.lifeos.app/v1/ingest/sms
3Header Authorization: Bearer + your iPhone token. Body JSON: {"text": Shortcut Input}.
4Send yourself a test SMS, then check the Parser Lab inbox.
Siri · “Log 500 ml”
1Shortcuts → New shortcut → Get Contents of URL: POST /v1/water {"ml": 500}.
2Name it Log 500 ml. Say “Hey Siri, log 500 ml”.
3Add it to the Action button or a Back Tap for 1-press logging.
